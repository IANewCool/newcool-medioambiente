# NewCool Medio Ambiente - Chile Verde

Portal educativo sobre medio ambiente y sostenibilidad en Chile.

## Demo

[https://medioambiente.newcool.io](https://medioambiente.newcool.io)

## Caracteristicas

- Buscador de oficinas SEREMI de Ambiente
- Puntos de reciclaje por comuna
- Calculadora de huella de carbono
- Guia de parques nacionales
- Normativa ambiental

## Tecnologias

- Next.js 15
- React 19
- Tailwind CSS 4
- TypeScript

## Desarrollo

```bash
npm install
npm run dev
```

## Parte del Ecosistema NewCool

Este modulo es parte de [NewCooltura Informada](https://informada.newcool.io) - Portal de instituciones publicas de Chile.
